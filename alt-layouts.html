Alternate Keyboard Layouts

Alternate Keyboard Layouts are one of my interests. I've designed multiple, and I've written chogalyzer (readme coming soon trust), a program to mathematically analyse layouts for comfort. The way layouts are evaluated are through a collection of subjectively objective metrics, as well as purely subjective feel. Some of these metrics include Same Finger Bigram, or SFB, which is how often you use the same finger twice, which is pretty uncomfortable. The two best layouts I've created are Whirl and Chog (writeup coming soon).
